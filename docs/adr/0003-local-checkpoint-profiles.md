# Select local checkpoints using server profiles shared with the Web UI

The API reads an explicitly selected `VIENEU_MODEL_PROFILE` from `config.yaml`, resolves paths relative to that YAML, and supports local v3 Turbo PyTorch checkpoints without a second model inventory. Profiles that disable streaming use complete inference one text chunk at a time, with serialized model access and cancellation/resource checks between chunks; only their bundled voices are exposed, while registry data is isolated by checkpoint identity. This keeps the existing default model and streaming clients unchanged when no profile is selected, and prevents checkpoint changes from mixing incompatible voice data or silently reverting to the official weights.
